# Chainsword visual references

The procedural in-game blade was revised after reviewing these miniature photos:

- [Space Marine Tactical Squad chainsword, Bitz Store](https://www.bitzstore.com/en/space-marines-wh40k-tactical-squad/353-space-marine-chainsword.html)
- [Space Marine Devastator chainsword, Egg Head Miniatures](https://eggheadminiatures.com/products/warhammer-40k-space-marine-devastator-squad-chainsword)
- [Assault Intercessors design context, Warhammer Community](https://www.warhammer-community.com/en-gb/articles/berjj60m/jump-pack-intercessors-kit-focus-blasting-a-classic-design-to-new-heights/)

Observed features used for the silhouette: one exposed toothed cutting edge,
a smooth armored back, a protected rounded tip, and a chunky motor housing near
the grip with vents and retaining pins. The geometry in `chainsword.gd` is drawn
for this game; reference photographs are not bundled in the runtime assets.
