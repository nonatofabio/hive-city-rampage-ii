# Editable audio sources

Three original CC0 clips used to create the four gunfire mixes are retained in
`source/`. Their hashes and download sources are in `manifest.json`.

Runtime WAV mixes and the original license notices live in `godot/assets/audio/`.
See [audio credits](../../godot/assets/audio/CREDITS.md). These source clips are not
exported into the game. The predecessor repository retains the original mixing tool.
