# Ashgate art provenance

## Servo-skull and spent brass

`ashgate_servo_casings.png` was created with the built-in image generation tool as a new atlas. The returned image is 1254×1254 with real alpha and four cells. `tools/prepare_ashgate_effects.py` imports the servo-skull at 40×56 and three spent-casing views at 12×6, 12×12, and 8×7. The HUD sayings are original Latin-styled snippets, not quotations from another game.

The player character images were reused. Per-view rigid weapon masks, wrist/elbow points, and ejection ports are recorded in `art/blender/weapon_rig.json`. Blender exports complete poses with rigid weapons and revised knee motion; no runtime limb cutting is introduced.

## Weapon sprites and fine aiming

`ashgate_weapon_fx.png` was generated with the built-in image generation tool and returned at 1254×1254 with real alpha. `tools/prepare_ashgate_effects.py` imports compact player/enemy bolt sprites and two muzzle-flash frames. It excludes the barrel stubs included in the generated flashes. Runtime rotation orients these isolated effects along shot velocity; character limbs still use complete Blender-rendered poses.

The existing cleaned player textures were reused for finer weapon aiming and heavier steps in `art/blender/ashgate_aim_rigs.blend`; no character regeneration was needed. Pose exports include both muzzle and barrel-axis coordinates.

## Effects, deaths, and scenery polish

`ashgate_vfx_atlas.png` and `ashgate_deaths_atlas.png` were created with the built-in image generation tool. Both arrived at 1254×1254. The effect sheet has real alpha, which is preserved including detached smoke and embers. The death sheet uses a magenta key and references the three enemies in `ashgate_atlas_clean.png`. Its row gutters are measured explicitly in the importer so the boss spires are retained. `tools/prepare_ashgate_effects.py` exports registered runtime sheets to `assets/effects/`; each animation keeps a consistent scale and ground anchor.

The cleaned atlas's existing bottom row is now used for facade, crate, barrel, and relay art as well. Their earlier generated texture cleanup is reused; no new scenery image generation was needed. Cached map lighting and brief explosion illumination are implemented in `isometric_game.py` and `siege_effects.py`.

## Player directional atlas

`ashgate_player_directions.png` supplies four additional player yaw views: rear, rear three-quarter, front three-quarter, and front. The existing cleaned side view is retained. Both generation and the background/texture cleanup used the built-in image generation tool. The player texture in `art/blender/textures/player.png` was the identity/style reference. The first generated sheet was then the input to the cleanup edit. Production source and extracted alpha textures are stored in this repository.

The returned atlas is 1254×1254 with a 2×2 layout. `tools/blender/prepare_direction_textures.py` imports each cell and removes its magenta color key. Per-view joints, muzzle sockets, and ground anchors are recorded in `art/blender/directions.json`. The added poses are rendered from `art/blender/ashgate_direction_rigs.blend`.

### Authored lower-body walk

`ashgate_walk_atlas_final.png` was generated using the built-in image_gen tool from the existing player art, then imported by `tools/prepare_ashgate_walk.py`. The final source has four columns and five views. Chroma-key removal, common row scale, belt registration, and source-proportion correction produce `rendered/walk/*.png`. Front/rear opposite-foot phases use runtime symmetry. The complete prompt history and rejected-atlas lessons are in `docs/design/ASHGATE_WALK_PROMPTS.md`.
